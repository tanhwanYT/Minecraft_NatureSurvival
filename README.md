# 원소능력자 마인크래프트

각종 원소의 특징들로 야생을 할 수 있는 협동 능력자 마인크래프트입니다.

`+`는 장점, `-`는 단점, `*`은 장점인지 단점인지 애매한 요소를 뜻합니다.

## 불

+ 엔티티를 때리면 불을 붙일 수 있음
+ 화염저항 버프 지급
+ 용암에서 이동 시 속도 증가
- 물에 닿을 시 큰 대미지를 입음
- 가끔 먹은 아이템이 불타 없어짐

## 물

+ 물속에서 공격력, 방어력 증가
+ 수중호흡, 돌고래의 가호 버프 지급
+ 물속에서 블록을 캐도 느려지지 않음
- 물 밖에서의 움직임이 느려짐
- 물 밖에서 숨을 쉴수 없음, 물 안 속에서는 호흡게이지가 달지 않음 
## 바람

+ 낙하대미지 제거
+ 신속 버프 지급
* 쉬프트를 오래 누르고 있으면 위로 날아감
* 아이템을 줍는 범위가 늘어남
- 최대체력 2칸 감소
- 인벤토리 9칸 감소

## 대지(땅)

+ 최대체력 2칸 증가
+ 원석이 제련된 상태로 나옴
+ 가끔 광물이나 자원이 2개씩 나옴
- 오버월드를 벗어나면 장점들이 사라짐 (네더, 엔더)
- 공격속도가 느림 (채굴피로 X)

## 전기

+ 신속, 야간투시 버프 지급
+ 비전투 상태에서 노란체력(흡수) 3칸을 받음
* 엔티티 공격 시 근처 다른 엔티티도 연쇄 대미지를 입음 (자신은 면역, 전기 이펙트가 조금 보이게)
* 가끔 근처에 번개가 침
- 물에 닿을 시 큰 대미지를 입음
- 배고픔이 빨리 닳음

## 빛

+ 바라보는 방향의 엔티티들이 발광됨
+ 재생, 포화 버프 지급
+ 주변 플레이어에게 약한 재생 효과 공유
- 어두운 곳에서 능력 약화 (재생, 포화 감소)
- 갑옷을 입을 수 없음 (신발, 바지, 모자는 허용)

## 금속

+ 쉬프트를 누르면 들고 있는 장비의 내구도 회복
+ 도구나 갑옷 제작 시 가끔 인챈트가 되어서 나옴 (보호 1~2, 효율 1~2, 내구성 등)
+ 화염 대미지를 적게 받음
+ 인벤세이브
- 이동속도 감소
- 인벤토리 9칸 감소

## 베타테스트 주의사항

현재 베타테스트에서는 전기 능력의 연쇄 대미지 코드가 꼬여 서버가 터지는 버그가 있습니다.
- 이후 수정됨
